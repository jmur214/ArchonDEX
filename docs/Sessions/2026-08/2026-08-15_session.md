## What was learned

- **THE FINDING: the day-1 stream's input channel is structurally empty.**
  Running the real constructor against the real notes in S3 returned an empty
  plan — **0 of 15 analyst notes carry a single `hypothetical_action`**, back to
  2026-07-27. Cause is the prompt working as written: `daily_v2` calls the
  actions "SMALL exploratory satellite tilts", says "**They are never
  executed**", and ends "**Omit the whole list if you have no small-tilt view.**"
  The model has complied every day.
- **The blast radius reaches C's shadow book**, which is the virtual rehearsal of
  this exact stream: 14 accrued points, every one `n_actions: 0, turnover: 0,
  positions: {}, book_nav: 1.0` against a twin that compounded to 1.0329 — and
  it reported `degraded: false, action: "applied"` every single day. A 14-day
  A/B has been comparing a permanently-100%-cash book to a compounding twin.
- **An always-empty channel is the most dangerous shape** because it degrades
  nothing: canonical, `reject_reason: none`, `degraded: false`, zero orders,
  forever. The clock census asks *did the artifact advance* — and every note DID
  advance, which is why nothing caught it. `[NN-FIRST-ARTIFACT]` has to be
  applied to the INPUT as well as the output.
- **A prompt that says an output is "never executed" is a behavioural
  instruction.** Wiring that output to a real order path silently invalidates the
  premise the producer was operating under. You cannot change the consumer
  without re-reading what the producer was told.
- **The analyst has been reading a degraded news panel every day** —
  `news_degraded` / `news_feed_degraded` / `news_panel_degraded` on all 8 most
  recent notes (2026-08-05 → 08-14, unbroken). The empty-tape saga is recorded
  as CLOSED at rev27; the analyst says otherwise, in prose, daily. Not diagnosed
  here; flagged, and scan 4 reads the same tape.
- **`performance_digest.generate()` has zero production callers** — the digest
  is not being produced at all. Same shape as T-331's `load_governor` finding.
- Two driver defects surfaced by writing an end-to-end test: `main()` had no
  root injectable (so a smoke test wrote its journal and heartbeat into the
  repo's own `data/`), and `record_run` **replaces** the status file, so any
  heartbeat block stamped before it is erased.
