# T-137 — 8-K event-type drift: the first different-data edge

## TL;DR

The strongest untested class (different DATA, structurally outside FF5 span)
got its first test, with the multiplicity trap handled the way the brief
demanded — and **nothing survives the family-wise bar.**

- **Panel built (Phase 1):** 183,278 8-K filings, 624 tickers, 1994-2026, via
  the EDGAR submissions API (structured fields ONLY — item codes + acceptance
  datetimes; NO text, per the no-LLM constraint). 164,278 usable post-2004
  (item-code regime). Cached under `data/edgar/8k/` (public domain; outside
  the pinned substrate-manifest dirs → no manifest regen needed; extending
  SUBSTRATE_DIRS is a director call when the event lane scales).
- **Event study (Phase 2):** 160,439 events in-window, anchored at the first
  close ≥ acceptance (16:00 ET cutoff; closes only — the T-135 corrupt-opens
  filter made opens unnecessary by avoiding opens entirely). Market-adjusted
  calendar-time portfolios per family member (overlap-correct).
- **Multiplicity (Phase 3):** pre-registered family {1.01, 2.01, 2.02, 2.05,
  4.02, 5.02, 7.01, 8.01} × {1, 5, 20}d = **24 two-sided tests**. Romano-Wolf
  StepM — hand-rolled (the `arch` package is not installed; CLAUDE.md
  no-new-deps + the T-132 precedent), studentized statistics, joint circular
  block bootstrap (B=1000, block=21d, seed 0, shared resample indices across
  members to preserve cross-member dependence), stepwise max-|t| ladder.
- **Result: survivors = NONE.** Family-wise critical value 2.95; the top
  observed |t| values: 5.02_20d −1.93, 8.01_1d −1.87, 2.05_5d −1.65,
  8.01_5d −1.60, 2.05_1d −1.55. Phase-4 factor gate: not reached (no survivor).

**Directional sanity (why this is a credible null, not a broken pipeline):**
the SIGNS line up with the literature — restatements (4.02) average
−29.8 bps/day at 1d, exit-costs (2.05) −12.2 bps/day, officer departures
drift negative over a month, Reg FD/other-events mildly negative. The
pipeline detects the expected economics; the magnitudes are simply too small
and noisy to clear a family-honest bar on a 21-year, 160k-event panel. This
is "priced at our scale," not "no signal in the data."

## What this does and does NOT close (the structural caveat)

**Closes:** UNCONDITIONAL drift by 8-K item type on large/mid-cap dailies.
The headline item codes are public within seconds and the market processes
them; no exploitable average drift remains.

**Does NOT close (by construction):** the DIRECTIONAL version. Item codes
carry no sign — a 2.02 can be a beat or a miss, so its unconditional drift
nets to ~0 mechanically. Conditioning on direction requires the filing TEXT
(or estimate data), which the no-LLM/structured-only constraint excludes
until the prompt-injection research lands. That is the natural upgrade path
for this dataset, and the 183k-filing panel + fetcher infra now exist for it.

**Coverage caveats:** 89/730 panel tickers had no CIK mapping in SEC's
current ticker file (delisted names) and 8 companies hit transient fetch
errors → the EVENT panel is slightly survivor-tilted, same direction as the
price substrate (T-092). Both lists reproducible from the fetch log/parquet.
