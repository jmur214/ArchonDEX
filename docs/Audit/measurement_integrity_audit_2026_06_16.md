**Workflow:** 6 agents, 5 area-finders + synthesis (read-only). Trigger: the user's observation that we keep turning up bugs that *cloud the real numbers*.

## The disease (one repeating failure mode)
Code on the measurement path that, when a load-bearing input is missing/broken, **degrades to a plausible-looking number instead of halting.** A wrong Sharpe/MDD looks identical to a right one. Every recent incident shares this signature: T-088 (risk-key mismatch → 5× risk on all-defaults), T-167 (`_normalize_df` clip → 19-ticker universe → 0.237 "collapse" artifact), T-171 (`dropna` dropped the crash-trough month → ~2× MDD understatement), T-175 (simfin-blind → 17-edge book quoted as 21-edge 0.751), T-177 (genes-inert → every GA candidate fails Gate-1).

## ⚠️ THE NEXT CLOUDED NUMBER (found): the 0.751 anchor is STILL degraded
T-175 was diagnosed + the parquet restored **locally**, but it is **not structurally closed**: `get_panel()` (`_fundamentals_helpers.py:90-92`) swallows any load failure to `None` → the 4 value/accruals edges abstain to `{t:0.0}`; the simfin parquet is **not baked + manifest-verified into the cloud image** the way OHLCV/macro are (`simfin_adapter.py:35-43` RAISES without `SIMFIN_API_KEY` even for a cached read); and the cloud path (`cloud_entrypoint.sh`) has **no `edges_blind`/`n_trades` guard**. So any fresh cloud image silently reproduces the 17-edge blind book and re-publishes ~0.751 as full-book. **Runner-up clouds on the same anchor:** regime degrades to "unknown" every bar if the macro panel isn't baked (T-164 GAP-2 → de-gross/HMM overlay silently OFF while the headline reads regime-aware); and a fabricated one-key risk fallback (`run_backtest_pure.py:443`). **Do not trust 0.751 as a full-book regime-aware number until the anchor re-runs with the census ON and asserts `fundamentals_blind==0 AND regime_unknown_bars~=0 AND n_trades>floor`.** (This is what B's T-180 must now gate on.)

## The 6 execution-census invariants (targeted — each catches a past bug)
1. **`edges_blind == 0`** — every active edge emitted ≥1 non-zero signal (minus an explicit `expected_dormant` allowlist); + a genes-non-empty precondition after `set_params`. Emit `census.edges_blind`, `census.edge_signal_counts` from `signal_collector.py`. *Catches T-177, T-175.*
2. **`n_in_panel == n_resolved − manifested_allowlist`** — universe didn't silently shrink; `fallback_to_static` is FATAL in measured/hermetic mode. From `backtest_controller.py` panel assembly + `mode_controller.py` universe-mode check. *Catches T-167, the universe_resolver fallback class.*
3. **`n_trades > floor AND trades_canon_md5 != EMPTY_MD5`** — the run actually traded; a zero-trade run HALTS, never a Sharpe=0.0 headline. In `cloud_entrypoint.sh` + `run_isolated.py` PASS-gate. *Catches T-175, T-164 (degraded cells uploaded exit-0), false determinism-PASS on constant-empty.*
4. **`fundamentals_blind==0 AND macro_panel_complete AND regime_unknown_bars~=0`** — the overlays were actually ON. *Catches T-175, T-164 GAP-2, the Engine-E advisory schema-drift (crisis brake silently 1.0).*
5. **zero-unaligned on every multi-series combination + no fabricated-zero in the cov input** — build `common` from all series' dropna'd indices, reindex, assert equal lengths + zero residual NaN; count MVO fillna(0) cells. *Catches T-171, T-173.*
6. **`config_provenance` sourced + filtered-key hash-stamped** — env-resolved path existed + parsed to >0 keys (no silent `{}`→all-defaults, no one-key fabricated risk dict); per-bar allocator-branch tally (mean_variance realized, Path-B ~0). *Catches T-088, the mean_variance→adaptive silent swap, the run_backtest_pure.py:443 risk fallback.*

## Proposed CLAUDE.md non-negotiables (await user sign-off — docs-system change)
1. **Fail closed in the measurement path; never degrade to a plausible number.** Any code producing a headline metric must HALT when a load-bearing input is missing/unbaked/stale/unparseable AND the edge/overlay/allocator is active — never abstain to zeros / fall back to a plausible path / emit a clean 0.0 that reads like a real bad measurement. Genuine graceful degradation must set an explicit `degraded=True`/`skip_reason` the gate treats as FAIL. Applies in measured/hermetic/cloud/anchor runs; the offline-graceful rule applies ONLY outside the measurement path.
2. **Every backtest emits and gates on an execution census.** Write a `census` block (the 6 invariants above) to performance_summary.json; a run is NON-CANONICAL (must not publish/upload/certify/quote) if any census check fails. Local + cloud paths call the SAME `assert_census`. Census std/var guards use tolerance (`std < 1e-12 or not isfinite`), never bare `== 0`, everywhere in the measurement path.
