# T-174 — VRP Edge (Equity-Implementable)

## 1. PRE-REGISTRATION (committed before any result)

### 1.1 What VRP is, and the honest limit up front

The variance risk premium = implied variance persistently exceeds
realized variance (VIX² > E[RV²]); the classic harvest is **short
variance** (sell options / variance swaps, collect IV−RV). **We are
NOT adding an options desk** — so the pure premium is NOT implementable
here. What an equity-only system CAN use is the **return-prediction
content** of VRP (Bollerslev-Tauchen-Zhou 2009: a rich VRP forecasts
higher forward equity returns; a compressed/negative VRP — realized vol
overtaking implied — flags poor forward returns / crisis onset). So the
testable equity form is a **VRP exposure-timing overlay on the base
book**, NOT a variance harvest. This must be stated as the ceiling: we
can only capture VRP's (weaker, regime-dependent) timing signal.

**Novelty vs what's already closed:** vol-target (T-055, closed
negative on 12-yr) times on REALIZED vol only. VRP adds the
forward-looking IMPLIED-vol (VIX) term. So the precise question is:
**does the implied-vs-realized spread (VRP) time the book's exposure
better than zero, net of cost — i.e. does VIX's forward-looking
information add harvestable timing value the realized-only overlays
lacked?**

### 1.2 Signal (fixed, causal)

- `RV21_t` = trailing 21-trading-day realized vol of ^GSPC daily log
  returns, annualized (×√252), in vol points (%).
- `VRP_t = VIX_t − RV21_t` (vol-point spread; positive = implied richer
  than realized = the normal premium state).
- All signal values at `t` use data through `t` only; the overlay
  weight `w_t` is applied to the base book's return at `t+1` (no
  lookahead).

### 1.3 Overlay (fixed — single canonical primary)

- **PRIMARY:** `w_t = 1.0` if `VRP_t ≥ M_t` else `0.5`, where `M_t` is
  the EXPANDING-window median of VRP up to `t` (no look-ahead, no free
  threshold parameter). Economic reading: when risk compensation is at
  or above its own historical norm, stay fully invested; when VRP is
  compressed/negative (panic, IV no longer cushioning realized), halve
  exposure. Applied: `r_overlay_{t+1} = w_t · r_base_{t+1} − cost·|w_t − w_{t−1}|`.
- **Cost:** exposure changes trade the book by `|Δw|`; modeled at
  **10 bps round-trip per unit |Δw|** (5 bps/side — the project's
  realistic-model mega-cap assumption; conservative for a broad book).
- **Sensitivities (reported, NOT the primary; N+=0):** `w_low ∈ {0.0, 0.5}`
  and a `VRP_t < 0` (sign-cross) trigger — to show robustness, not to
  select.

### 1.4 Substrate + gate (fixed)

- Substrate: the trustworthy re-anchored base book, daily, 2000-2025
  (where VIX+GSPC overlap the base — full 26yr). VRP needs ~1yr warmup
  for the expanding median → effective test ~2001-2025.
- Metric: Δ Sharpe (overlay − base) with **block-bootstrap ci_low**
  (block=Politis-White auto, n_iter=1000, seed=42, per CLAUDE.md #6),
  plus MDD and CAGR. MBL-aware: a 24-yr daily window clears MBL for
  any SR the overlay could plausibly add.
- **GATE (pre-registered): the VRP overlay is a real harvestable edge
  iff Δ Sharpe `ci_low > 0` NET-of-cost on the deep substrate.** Point
  Δ > 0 with ci_low ≤ 0 is NOT a pass (CLAUDE.md #6). Per #9 the
  verdict is on this substrate.

### 1.5 N-trials

**N_trials += 1** (one canonical pre-registered signal). The
sensitivities are robustness reads on the same hypothesis, not new
trials. Pre-registered before unblinding per CLAUDE.md #7.

### 1.6 Expected outcome (pre-stated, to avoid post-hoc spin)

Prior is skeptical: VRP's return-prediction is real but weak and
concentrated at monthly+ horizons; as a daily equity overlay net of
cost it may not clear ci_low > 0 — like the realized-vol overlays
before it. A pass would be the first new harvestable edge post-fork; a
fail closes VRP-in-our-form (the honest, likely outcome) and leaves
the bought-MF sleeve (T-170/171/173) as the crisis lever and a NEW
edge still owed.
